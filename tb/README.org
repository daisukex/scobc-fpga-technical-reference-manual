* Install Environment
#+BEGIN_SRC
make generate_ip
#+END_SRC

Copy the Verilog/VHDL model released by the memory vendor to the bench directory.
#+BEGIN_SRC
cp {flash model path} ./bench/flash_model
cp {sram model path} ./bench/sram_model
#+END_SRC

Store the simulation model in the ./bench directory. There are no restrictions on the name of the directory.
This verification environment requires the cy15b104, s25fl256l and cy7c1061ge simulation models.
It can be downloaded from the infineon website.

Copy the AhbToAxi.v file from the implement directory.
#+BEGIN_SRC
cp ../implement/cm3/AhbSToAxi_design.v ./bench/AhbSToAxi.v
#+END_SRC

* Execute Simulation
#+BEGIN_SRC
make TESTCASE={testcase name}
#+END_SRC
